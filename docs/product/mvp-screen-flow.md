# Neo-Anki MVP 화면 흐름

## 목적

이 문서는 `mvp-scope.md`에서 확정한 기능 범위를 실제 와이어프레임 작업 단위로 변환한다.

원칙은 다음과 같다.

- 화면 수를 늘리기보다 하나의 핵심 흐름이 끝까지 이어지게 한다.
- 신규 사용자와 기존 Anki 사용자는 진입만 다르고 학습 경험은 하나로 합친다.
- 홈은 관리 화면보다 오늘의 학습으로 진입하는 화면이다.
- 고급 설정은 최초 진입에서 강제하지 않고 덱 내부에서 점진적으로 노출한다.

# 1. 화면 그룹

## A. 진입과 홈

### A1. 빈 홈

대상: 처음 실행한 사용자

핵심 목적:

- 새 덱을 만든다.
- Anki 덱을 가져온다.

필수 요소:

- `새 덱 만들기`
- `Anki 덱 가져오기`
- 강제 온보딩이나 긴 설명 없음

### A2. 사용 중인 홈

대상: 하나 이상의 덱이 있는 사용자

핵심 목적:

- 오늘 무엇을 학습해야 하는지 확인한다.
- 전체 학습 또는 특정 덱 학습을 시작한다.
- 내 덱 목록을 확인한다.

필수 요소:

- 오늘 남은 전체 카드 수
- 덱별 오늘 학습량
- `오늘 학습 시작`
- 덱 목록
- 새 덱 추가

# 2. 덱 진입 흐름

## B1. 새 덱 만들기

필수 입력:

- 덱 이름

제외:

- 시험 유형 필수 선택
- 목표일 필수 선택
- 사용자 유형 설문
- 긴 설정 마법사

완료 후 이동:

- 빈 덱 상세 화면

## B2. Anki 덱 가져오기

단계:

1. `.apkg` 파일 선택
2. 가져오기 진행
3. 결과 확인
4. 가져온 덱 상세로 이동

필수 결과 정보:

- 가져온 덱 수
- 가져온 카드 수
- 확인이 필요한 카드 수
- 지원되지 않은 항목

## B3. 가져오기 결과

핵심 목적:

- 데이터가 무엇까지 정상적으로 들어왔는지 신뢰할 수 있게 한다.

주요 행동:

- 결과 상세 보기
- 가져온 덱 열기
- 학습 시작

# 3. 덱 내부 흐름

## C1. 덱 상세

핵심 목적:

- 이 덱의 현재 상태를 이해한다.
- 바로 학습을 시작한다.
- 카드와 목표 설정으로 이동한다.

필수 요소:

- 덱 이름
- 오늘 학습량
- 신규 / 복습 카드 수
- 아직 보지 않은 카드 수
- 어려운 카드 수
- 목표일이 있으면 남은 날짜
- `학습 시작`
- `카드 보기`
- `목표 및 학습 설정`

## C2. 카드 목록

핵심 목적:

- 덱에 어떤 카드가 있는지 확인하고 관리한다.

필수 요소:

- 카드 검색
- 카드 추가
- 카드 편집
- 카드 삭제
- 카드 중요도 표시

MVP에서는 복잡한 태그, 고급 검색, 사용자 정의 컬럼은 제외한다.

## C3. 카드 추가와 편집

MVP 기본 유형:

- 질문과 답변
- 빈칸

필수 요소:

- 카드 유형
- 질문 또는 본문
- 답변
- 이미지 첨부
- 중요도: 핵심 / 일반 / 보충
- 저장

기본값:

- 질문과 답변
- 중요도 일반

## C4. 목표 및 학습 설정

필수 요소:

- 목표일 없음 / 날짜 지정
- 하루 신규 카드 상한
- 오늘 학습량 수동 조정
- 목표 변경 후 계획 재계산 결과

이 화면은 덱 생성 과정에서 강제로 노출하지 않는다.

# 4. 학습 흐름

## D1. 학습 시작 전 요약

핵심 목적:

- 시스템이 오늘 무엇을 왜 보여주는지 이해한다.
- 사용자가 시작 전에 분량을 조정한다.

필수 요소:

- 복습 카드 수
- 신규 카드 수
- 핵심 카드 수
- 어려운 카드 재등장 수
- 분량 조정
- `학습 시작`

## D2. 질문 화면

필수 요소:

- 질문 또는 빈칸 본문
- 현재 진행 수
- 남은 카드 수
- `답 보기`
- 카드 편집
- 카드 보류

## D3. 답변과 평가 화면

필수 요소:

- 정답
- Again / Hard / Good / Easy
- 각 평가에 대응하는 단축키
- 현재 진행 수와 남은 카드 수

신규 사용자에게는 첫 학습에서만 평가 의미를 짧게 표시한다.

## D4. 어려운 카드 보류 상태

발생 조건:

- 같은 세션에서 한 카드가 두 번 Again을 받음

동작:

- 현재 주 흐름에서 잠시 제외
- 다른 카드를 계속 학습
- 세션 마지막의 어려운 카드 묶음으로 이동

필수 안내:

- 왜 보류되었는지
- 카드가 사라진 것이 아니라는 점
- 즉시 다시 보기 가능 여부

## D5. 학습 완료

필수 요소:

- 오늘 학습한 카드 수
- 신규 / 복습 완료 수
- 어려운 카드 수
- 남은 카드 수
- `어려운 카드 다시 보기`
- `다음 학습으로 넘기기`
- 홈으로 이동

# 5. 지원 화면

## E1. 백업과 기본 설정

MVP 필수 요소:

- 수동 백업 생성
- 백업 위치 확인
- 데이터 삭제 전 확인
- 기본 단축키 확인

동기화, 계정, 클라우드 연결은 후순위다.

# 6. 핵심 사용자 흐름

## 신규 사용자 흐름

```text
빈 홈
→ 새 덱 만들기
→ 빈 덱 상세
→ 카드 추가
→ 학습 시작 전 요약
→ 질문
→ 답변과 평가
→ 학습 완료
→ 사용 중인 홈
```

## 기존 Anki 사용자 흐름

```text
빈 홈 또는 사용 중인 홈
→ Anki 덱 가져오기
→ 가져오기 결과
→ 덱 상세
→ 학습 시작 전 요약
→ 질문
→ 답변과 평가
→ 학습 완료
```

## 목표 기반 흐름

```text
덱 상세
→ 목표 및 학습 설정
→ 계획 재계산 결과
→ 학습 시작 전 요약
→ 학습 세션
→ 학습 완료
```

## 반복 루프 방지 흐름

```text
질문
→ 답변과 평가: Again
→ 재등장
→ 다시 Again
→ 어려운 카드 보류
→ 다른 카드 계속 학습
→ 학습 완료
→ 다시 보기 또는 다음 학습으로 넘기기
```

# 7. 와이어프레임 우선순위

## P0: 먼저 그릴 핵심 8개

이 8개만 연결해도 MVP의 핵심 경험을 검토할 수 있다.

1. 빈 홈
2. 사용 중인 홈
3. 새 덱 만들기
4. 덱 상세
5. 카드 추가
6. 학습 시작 전 요약
7. 질문 / 답변과 평가
8. 학습 완료

질문 화면과 답변 화면은 하나의 프레임에서 상태 전환으로 표현해도 된다.

## P1: 다음에 추가할 4개

9. Anki 덱 가져오기
10. 가져오기 결과
11. 목표 및 학습 설정
12. 어려운 카드 보류 상태

## P2: 흐름 검증 후 추가할 3개

13. 카드 목록
14. 카드 편집 상세 상태
15. 백업과 기본 설정

# 8. 첫 와이어프레임 과제

첫 작업에서는 P0 화면만 저충실도로 그린다.

검증 질문:

- 처음 실행한 사용자가 다음 행동을 즉시 알 수 있는가?
- 덱 이름만 입력하고 바로 카드 추가로 넘어갈 수 있는가?
- 덱 상세에서 학습 시작이 가장 강한 행동으로 보이는가?
- 사용자가 오늘 학습량의 구성을 이해할 수 있는가?
- 복습 중 질문, 답 확인, 평가가 빠르게 이어지는가?
- 세션 종료 후 어려운 카드가 별도로 남아 있음을 이해할 수 있는가?

# 9. 와이어프레임에서 아직 결정하지 않을 것

- 최종 색상과 타이포그래피
- 브랜드 로고
- 카드 유형 전체 구조
- 상세 SRS 간격 표시 방식
- 고급 통계 차트
- 모바일 레이아웃
- 협업과 공유 흐름
- AI 기능 UI

# 10. 다음 결정

P0 와이어프레임을 그리기 전에 가장 먼저 확정할 것은 **홈 화면의 정보 우선순위**다.

홈은 다음 질문에 답해야 한다.

1. 오늘 무엇을 공부해야 하는가?
2. 어느 덱에서 얼마나 남았는가?
3. 어디를 눌러 바로 시작하는가?
4. 새 덱이나 Anki 덱은 어디서 추가하는가?
