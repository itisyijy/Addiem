- 강조 구간: 하이라이트 주석 · 붉은 글씨 · ★ · 볼드(PDF), highlight · 붉은 색 · ★ · b(PPTX) 모두 잡힘. 미연결 강조 구간 정렬 R11 (붉은 글씨 · ★ > 하이라이트 > 볼드). 쪽 지도, 탭 숫자 · 덱 헤더 "자료 N · 미연결 N" 이 연결/끊기 때마다 바로 바뀜.
- 기존 카드 연결: 검색 → [연결] → "카드 1장" · "직접 연결", 한 구간에 카드 2장, [끊기] → DB 연결 삭제 · 숫자 원복. I2 [연결 바꾸기] → 자료 화면이 그림·표 탭 · 그 줄 연결 칸을 연 채로 열림, [학습 자료에서 열기] → 그 자료 · 쪽 · 구간이 활성.
- IT13: 그림·표 구간은 강조 수 · 미연결 수 · 임베딩(카드 30 · 구간 354, 영역 구간 제외)에서 빠짐.
- PPTX 목록: p:pic · 그룹(2단 중첩 변환 [0.1547, 0.2916, 0.1094, 0.1944] 계산값과 같음) · Fallback 그림 제외 · 외부 링크 제외 · EMF/WMF/TIFF "미리 볼 수 없는 형식 · 만들 수 없어요" · a:tbl 합친 칸(gridSpan/hMerge, rowSpan/vMerge) · 칸 안 여러 문단 · 특수 글자 이스케이프(`&#123;&#123;c1:&#58;…`, `&lt;b&gt;`, `&amp;`).

- 칸 나누기 정확도: 괘선 5×3 · 글자 6×3(오른쪽 정렬 숫자 포함) · 북탭 · 칠한 괘선 모두 칸 글자까지 정확. PDF 합친 칸은 빈 칸(문서대로).
- 표 세 방식: 칸 빈칸 = 칸 하나에 Cloze 노트 하나 · 묻는 칸만 `{{c1::}}` · 같은 열 "…"(IT5), 행마다 한 장(열 2개 "선형회귀 — 변수 수? RMSE?" / "변수 수: 5<br>RMSE: 12.40"), 열을 목록으로 = "Neo-Anki 목록 회상" 노트 "뜻 3가지를 표 순서대로". 조사(은/는) 맞음. 넣을 곳 기본값 R8(가까운 연결 카드 덱 "1장 개요", 없으면 자료 덱). 표 창의 행 빼기 · 칸 고치기 · 열 넣기 · 카드 수 갱신.
- 그림: [그림 가리기 카드로] → 편집기 [카드 만들기]("카드 만들기를 누르면 바로 카드가 생기고 자료의 그림과 이어져요"), Image Occlusion 노트 2장 · 연결. [그림을 앞면에 둔 카드] → 1600×1067 로 자른 PNG 를 미디어에 저장, 답은 HTML 이스케이프. 움직이는 GIF 는 가리기 꺼짐.
- 끌어서 잡기: 점선 · 손잡이 4개 · "끌어서 잡음 · 1600×1098", 글자 있는 영역은 [표로 카드 만들기] 켜짐, 없는 영역은 꺼짐 + 까닭, [영역 다시 잡기], Esc 로 메뉴 → 고른 것 순서로 닫힘.
- 차례로 만들기: 고른 순서(목록 순)로 열림, 메뉴 Esc · 표 창 [취소]는 그 자리에 머묾, [다음]으로 건너뜀, 카드를 만들 때만 다음으로(그림 → 표, 표 → 제안), 창 머리 "차례로 만들기 2 / 3", 마지막 "끝내기", [그만하기]. PPTX 타일 체크와 목록 체크가 같이 움직임.
- 스캔본: 그림·표 탭으로 열리고 강조 두 탭 꺼짐, 안내 두 줄, 자동 찾기 없음, 잡은 영역 메뉴의 표 꺼짐 "스캔본이라 글자가 없어요 · 그림 카드만 돼요", 그림 앞면 카드 생성 · I2 에 잘린 그림.
- 배지 숫자: 쪽 이름표 "그림 1-1 · 카드 2장", 목록 · 타일 "카드 N장", 카드 지우기 뒤 숫자 줄어듦.
- I2: 답 면에서만 열림(질문 면에서 S 를 눌러도 패널 없음, 열어 둔 채 다음 카드로 가면 질문 면에서 숨음), PDF 표 = 카드와 같은 표 + 답 칸 칠함, 행 카드 · 목록 카드(열 전체) 칠함, PPTX 합친 칸 표 colspan/rowspan 그대로 · 답 칸 칠함, 그림 600px 자름.
- 되돌리기: 표 카드 5장 · R1 초안 3장 토스트 [되돌리기] → 노트 삭제 · 연결 삭제 · `card_change.kind='draft'` `undone_at` 기록, 영역 구간은 남음(IT12). 두 번 되돌리기는 막힘(코드).
- .apkg 내보내기: 그림 · 표 영역 노트에만 `출처::t4_multi::2쪽` · `출처::t4_slides::슬라이드_8` · `출처::t4_scan::1쪽` (DB note.tags 는 안 바뀜). 연결을 끊고 다시 내보내면 태그 빠짐. 새 인스턴스로 다시 가져오면 `출처::` 태그 0개.
- 모델: 없을 때 중요도 화면 배너 "자료로 중요도를 제안하려면 분석 모델이 필요해요 · 약 490MB"(내려받기는 누르지 않음), 초안 화면 "분석 모델이 없어 비슷한 카드·근거 검사는 하지 않았어요". 있을 때 자료 추가 뒤 자동 분석 "분석 중 3/5 · t4_150p.pdf", 자동 연결 1건(0.887), 초안의 "비슷한 카드 있음 2"(기본 체크 끔) · "근거 미확인 1"("이 방법은 1950년대에 처음 쓰였다" 짚음), 자료 목록 "분석 모델 있음".
