- **소리 · 읽어주기**: 기본은 소리 자동 재생 켬 · 읽어주기 끔(첫 읽어주기 카드에 안내). 질문 면 front.wav, 답 면은 뒷면 소리만(back.wav). R 은 질문 면 [front.wav → tts en], 답 면 [front.wav → tts en → back.wav → tts ko]. 읽어주기 자동 재생을 켜면 질문 [front.wav → tts en], 답 [back.wav → tts ko] 순서. 소리 끔 + 읽어주기 켬이면 읽어주기만. 내장 음성(Supertonic) 재생 확인
- **기출 우선**: 같은 중요도 신규에서 기출(E4 · E6)이 앞 순서보다 먼저 뽑힘(상한 2), 소리 덱에서도 기출 카드가 먼저
- **목표일 · 하루 상한**: 3일 뒤 4장(올림), 당일 포함 3장, 오늘이 목표일 전부, 지난 목표일 전부 + 덱 상세 "목표일이 지났어요 · D+5", 상한이 이기면 덱 상세 "하루 5장이 필요한데 상한이 2장이에요", 상한 0 → 신규 0. 상한 2 저장 후 그날 두 장 뒤 덱 0장
- **쉬기 · 보관**: 3일 쉬기 → 홈 "쉬는 중 · 10/17까지", 오늘 합계에서 빠짐, [지금 다시 시작] 복귀. 보관 → 홈에서 빠지고 "보관한 덱 1", 설정 [보관 해제]로 복귀
- **시험 전 회독**: 압축은 카드 일정 열 전부 변화 없음(diff 동일), review_log kind='cram', 오늘의 학습 3장 그대로. 혼합은 fed 1 로 일정 반영, 오늘 예정 카드를 보면 오늘 학습에서 빠짐(3→2), 회독 진행 0% → 33%, mode 'mix' 세션
- **학습일 경계 계산**: 경계 4시 기준 01:xx 는 10/15 로 처리(홈 날짜 · 세션 study_day · due_day). 설정에서 경계 시각을 바꾸면 홈 날짜 · 오늘 분량이 바로 바뀜, 설정 UI 로 4시 복구 확인

## 못 해 본 것 (이유)

- **실제 새벽 4시 경계 통과**: 시계를 바꾸지 않기로 해서 경계 시각 설정(4 → 1)으로만 흉내냄(T1-06). 4시에 실제로 넘어갈 때 화면 쪽 `studyDate()` 갱신은 보지 못함
- **3일 지난 접힘 카드의 자연 복귀**: 날짜를 기다릴 수 없어 DB `buried_until` 을 오늘로 고쳐 확인
- **혼합 회독의 두 번째 Again 접기와 회독 끝 재제시(P2)**: 시간 관계로 압축 쪽 접기만 확인
- **ChatGPT 채점 보조(G)**: 버튼 표시까지만. AI 상태는 T5 범위
- **편집(E) · 원자료 패널(S)**: T1 흐름 밖이라 키 안내만 확인
- **여러 덱 합쳐 학습(홈 [오늘 학습 시작])의 덱 블록 순서**: 숫자만 보고 순서 검증은 못 함
- **TTS 엔진 메모리 · OS 음성 대체**: T7 · T8 범위
