## 6. 통과한 것

- 빈 홈 · 덱 있는 홈 · 쉬는/보관/시험 전 회독 안내가 있는 홈, 새 덱 창, 덱 상세(빈 덱 포함), 덱 메뉴, 하위 덱 만들기 창, 내보내기 창, 덱 삭제 창, 카드 목록 · 편집 창, 카드 추가 7가지 유형, 목표 및 학습 설정, 학습 계획(덱 · 모든 덱), 중요도 정하기, 카드 점검 · 나누기 제안 창, 가져오기(Anki · JSON · CSV · 미리보기 · 결과), 설정 전체(동기화 연결 전/후), 모든 데이터 삭제 창, 동기화 설정 창 · 팝오버, 학습 전 요약, 학습(서술형 · 기본 · 양방향 · 빈칸 · 목록 · 선택형 · 그림 가리기, 문제/답 두 면), 채점 보조 확인, 학습 끝(접어둔 카드 처리), 시험 전 회독(혼합 · 압축), 학습 자료, 카드 초안 만들기 · 초안 검토, 가리기 편집기를 1280 · 1920 라이트/다크에서 열어 위 표 밖의 잘림 · 겹침 없음
- 1280 · 1920에서 위 T6-05/06/07 외 가로 스크롤 없음, 글자끼리 겹침 없음 (자동 검사의 겹침 후보는 모두 반투명 상단 바 · 아래 고정 막대 아래로 지나가는 의도된 경우였음)
- Tab 순서: 홈 → 상단 바 → 시작 버튼 → 덱 행 순으로 자연스러움. 덱 상세 · 카드 목록 · 카드 추가 · 설정 · 가져오기 · 자료 · 요약 · 학습 · 끝 화면 모두 초점 링(2px outline, 다크는 #a79fff)이 보임
- 모달 초점 가두기: 새 덱 · 편집 · 삭제 · 모든 데이터 삭제 · 동기화 설정 창에서 Tab이 창 밖으로 안 나감
- Esc: 메뉴(덱 관리 · 중요도 칩 메뉴)는 닫히고 연 버튼으로 초점이 돌아감, 편집 창 Esc는 학습을 끝내지 않고 창만 닫음, 초안 검토 Esc는 "초안 3장을 버릴까요?" 확인, 가리기 편집기 Esc는 마칠지 확인
- Enter: 새 덱 이름 입력 후 Enter로 만들기(빈 이름이면 아무 일 없음), 초점이 버튼에 있으면 화면 Enter보다 버튼이 먼저 받음(홈 · 덱)
- 중요도 보드는 끌기 대신 칩 Enter → 핵심/일반/보충 메뉴로 키보드 조작 가능
- 키보드만으로 JSON 붙여넣기 → 미리보기 → 가져오기, 서술형 답 쓰기 → Ctrl Enter 비교 → 1–4 평가, 목록 회상 Space · X · Enter, 선택형 1–4 고르기 → Space 확인
- 동작 줄이기(reduce)에서 배경 정지, 학습 화면에서 배경 없음
- 대비: 홈 화면(배경 위 큰 숫자 · 범례 · 날짜 칩 · D-n 배지)은 라이트/다크 12시점 모두 기준 통과, 다크 테마는 블롭 위 보조 글자 통과
- 문구: 2장 하단 목록

## 7. 못 해 본 것 (이유)

- Figma 비교: 선택 항목이고 시간 안에 화면 수가 많아 하지 않음
- 로그인이 필요한 화면(Google · ChatGPT 연결 과정), S1-6 복구 화면(시작 오류를 일부러 만들어야 함), 동기화 충돌 · 백업 복구 · 다른 기기 창(T3 범위)
- 연결 자료 패널(S) · 소리 다시 듣기(R): 연결된 자료가 있는 카드와 소리 카드를 만들지 않음
- I 단축키: 네이티브 파일 창이 열려 CDP로 닫을 수 없어 누르지 않음
- 실제 창을 1024×700으로 만드는 것: 창 최소 크기 1180×760 때문에 불가 (에뮬레이션으로만)
- 창이 다른 창에 가려졌을 때(최소화가 아닌 경우)의 visibilitychange, 고주사율 모니터에서의 CPU
- 블롭이 의도대로 움직일 때의 배경 대비 시점 측정 (T6-01 수정 뒤 다시 필요)
- 화면 낭독기(NVDA 등)로 실제 읽기 순서 확인: 접근 이름은 DOM으로만 봄
