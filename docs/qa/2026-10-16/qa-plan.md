# Neo-Anki 전반 테스트·QA 계획 (2026-10-16)

대상: `qa/integration` = main(4ba58a1 이후) + feat/tts + feat/source-figures(8.4 2단계까지)를 로컬에서 합친 것. main에 머지하기 전 마지막 통합 검사다.

## 1. 원칙

- 데이터는 모두 `%TEMP%` 아래 스크래치 폴더(`NEOANKI_DATA_DIR`)와 별도 WebView2 프로필만 쓴다. 실제 `%APPDATA%\io.github.itisyijy.neoanki`와 개인 .colpkg는 열지 않는다.
- 로그인(Google · ChatGPT)은 하지 않는다. AI는 `NEOANKI_AI_FAKE`, 동기화는 `NEOANKI_SYNC_FOLDER`(FolderStore)로 대신한다. 둘 다 debug 빌드 전용이다.
- 설치 파일은 만들기만 하고 이 PC에 설치하지 않는다. 포터블 exe로 실행한다.
- 앱은 PID나 경로로만 끈다(`taskkill /IM` 금지).
- 문제를 찾아도 QA 트랙에서 바로 고치지 않는다. 재현 단계 · 기대/실제 · 심각도 · 의심 파일 · 캡처를 남기고, 고치는 일은 따로 맡긴다.

## 4. 심각도

- **치명**: 데이터 손실 · 손상, 앱이 켜지지 않음, 보안 구멍(파일 탈출 · 스크립트 실행), 동기화가 다른 기기 데이터를 망가뜨림
- **높음**: 주요 흐름이 막힘, 잘못된 결과(복습 일정 · 통계), 잘못된 행동을 부르는 문구
- **중간**: 우회 가능한 버그, 상태 표시 오류, 잘림 · 겹침
- **낮음**: 다듬기, 일관성
