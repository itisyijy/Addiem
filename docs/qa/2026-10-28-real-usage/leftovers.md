# v0.1.1 뒤에 남은 것 (다음 라운드)

- 2026-10-29, v0.1.1 (`fix/v0.1.1` `bce50c7`) 기준.
- 아래 표는 실사용 QA(T1–T9 · R)와 다시 QA(V1–V9)의 발견 가운데 **고친 항목 장부에도, 다시 QA의 "고쳐짐" 판정에도 ID가 없는 것**을 자동으로 뽑았다. 같은 파일을 고치며 함께 고쳐진 것이 섞여 있을 수 있다. 다음 라운드는 항목마다 재현부터 한다.
- 모두 124건: 중간 1 · 낮음 50 · 참고 73.

## 먼저 볼 것

- **디자인 검토**
  - 넓은 창 위 토스트 자리(I181)
  - 끝 화면의 "다시 볼" 줄(D1)
- **성능 (V7)**
  - 2만 줄을 다 불러온 뒤 Ctrl+A 15.9초(V7-01). 가상 목록이 필요하다.
  - 덱 상세 +25%(V7-03)
  - 평가 한 번의 IPC 2 → 10 ms(V7-04)
  - 복구 +24%(V7-05)
  - 2만 줄 목록의 메모리(V7-06)
  - 홈 직후 동기 명령 `cram_plan` · `plan_conflict`(V7-07)
- **0.1.0에서 생긴 상태는 저절로 고치지 않는다**: 이미 갈라진 동기화(K45), 0.1.0 때 복사한 폴더(K46), 0.1.0 때 잠금을 바꾸기 전의 Drive 백업(K48). 릴리스 노트에 안내했다.
- **사람이 직접 확인할 것**: 실제 Windows 한글 IME, 탐색기 끌어 놓기, 실제 고대비 테마, 1366×768 125% 노트북, 실제 ChatGPT 오류(한도 · 만료 · 오프라인).
