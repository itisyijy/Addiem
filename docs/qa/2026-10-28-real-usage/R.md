# R · 실계정 확인 (Google Drive · ChatGPT)

- 날짜: 2026-10-29 00:30–01:30 (학습일로는 10-28)
- 대상: 설치본 Addiem 0.1.0(= main `2e72cd3` 앱 코드, 실제 Google 키 포함)
- 목적: 가짜 모드(T5 · T7)로 본 흐름이 실제 Google Drive · ChatGPT에서도 그대로인지 확인한다. 찾기만 하고 고치지 않는다.
- 로그인은 사용자가 기본 브라우저에서 직접 했다(테스트 Google 계정, 사용자의 ChatGPT 계정). 코디네이터는 암호 · 이메일을 입력하지 않았다. 계정 이메일은 이 문서와 캡처에 남기지 않았다.

## 통과한 것

- **Google 로그인**: 5분이 지나면 "시간이 지났어요 · 5분 안에 로그인을 마치지 않아 기다리기를 멈췄어요" → [다시 시도]로 새 로그인 탭이 열린다. 두 번째에 연결됐다.
- **키체인 분리**: `ADDIEM_DATA_DIR`마다 `google-refresh-token@<해시>`로 따로 저장된다. 실제 앱의 항목은 건드리지 않았다.
- **수렴** (A → B → A → B 순서로 맞춤, 각 6–11초):
  - 카드 123 · 덱 17 · 복습 기록 203건으로 양쪽이 같다.
  - A만 고친 노트는 B에, B만 고친 노트는 A에 간다.
  - 같은 노트를 A(먼저) · B(2초 뒤)에서 고치면 B 쪽이 남고, 두 기기 모두 "두 기기에서 고친 카드" 기록과 토스트가 생긴다. 두 버전이 다 남는다.
  - 같은 카드 3장을 두 기기에서 같은 날 학습 → 기록 6건이 모두 남고 다음 복습일이 양쪽 같다(11-21).
- **잠금**:
  - A에서 켜면 B에 "다른 기기에서 Drive 데이터를 암호로 잠갔어요" + 암호 칸. 맞는 암호로 합치기 약 10초.
  - A에서 끄면 B에 "집 PC에서 잠금을 풀고 Drive에 다시 올렸어요". 잠근 동안 A가 고친 내용이 B에 온다.
  - 잠그기 전 Drive 백업은 잠금을 켠 뒤에도 미리보기가 된다.
- **오프라인**: 터널을 끄면 Drive 버튼이 "Google Drive · 오프라인 · 아직 올리지 못한 변경 1건 · 이 기기에 저장됨". 터널을 다시 켜면 아무것도 누르지 않아도 13초 뒤 맞추기 시작, 23초에 올리기까지 끝. A가 그 변경을 받았다.
- **연결 끊기**:
  - B [Drive 데이터 남기기](기본 선택): 3초, B 토큰만 지워지고 A는 계속 맞춘다.
  - A(마지막 기기) [Drive에서도 지우기]: 버튼이 "끊고 Drive에서 지우기"로 바뀌고 4.6초. 백업 2개와 동기화 데이터를 지우고 권한을 거둔다. 키체인이 비고 A 데이터(카드 123 · 복습 203)는 그대로다.
- **예전 이름 백업**: Neo-Anki 시절 `neoanki-2026-10-20-1457.zip`이 목록에 기기 이름 없이 보이고 미리보기가 된다.
- **ChatGPT** (사용자 요금제, 모델 `gpt-6.1-sol`):
  - 연결: 안내 창(보내는 것 · 보내지 않는 것) → 로그인 → "내 ChatGPT 요금제를 쓰고 있어요" 환영 창 한 번.
  - 카드 초안 7.2초: 구간 3개 → 카드 3장, 구간 연결 · 중요도 포함.
  - 채점 보조 9.9초: 맞은 점 1 · 빠진 점 1 · 추천 평가 Hard.
  - 오답 보기 제안 4.6초: "SYN-ACK", "FIN", "RST" (정답 SYN, 기존 보기 ACK와 겹치지 않음).
  - 나누기 제안 3.9초: 4항목 답 → "질문 하나에 물음이 2개" 2장 제안.
  - AI로 확인 7.4초.
  - 조건이 안 맞으면 보내지 않고 바로 안내한다: 구간 0개("구간은 1–10개 고를 수 있어요"), 답 항목 2개("답 항목이 3개 이상일 때 나눌 수 있어요"). 보낸 횟수도 늘지 않는다.
  - 설정의 "보낸 횟수 이번 달 8번 · 마지막 오늘 01:23"이 실제 요청 수와 같다.
  - 연결 끊기 1.3초, "ChatGPT 연결을 끊었어요 · 이미 만든 카드는 그대로예요", 키체인이 빈다.

## 못 해 본 것

- Google 동의 화면의 앱 이름 · "확인되지 않은 앱" 경고, Google 계정의 연결된 앱 목록: 사용자 브라우저라 보지 못했다. 사용자 확인을 기다린다.
- ChatGPT 쪽 오류(요금제 한도 · 대상 아님 · 토큰 만료 · 오프라인)를 실계정으로 만들지 못했다. 가짜 모드(T7)로만 봤다. ChatGPT 연결 해제가 OpenAI 쪽에서도 풀렸는지는 확인하지 못했다.
- 마지막 기기에서 [남기기]로 끊을 때의 권한 해제(10-15에도 단위 테스트로만).
- PDF 자료로 카드 초안: PDF 읽기는 화면(pdf.js)에서 일어나 화면 없이 넣은 PDF는 "pending"에 머문다. PPTX 자료로 대신했다.
- 그림 · 소리가 있는 데이터의 Drive 동기화, 30분 주기, 날짜가 바뀐 뒤의 하루 백업.

## 하네스 메모

- 처음 만든 터널은 Google이 닫은 연결을 클라이언트 쪽에서 닫지 않았다. 그래서 B의 [합치기]가 "os error 10054"로 세 번 바로 실패했다. 터널을 고치자 3.7초에 됐다. 앱 문제로 세지 않았다(문구만 R-04).
- 화면을 거치지 않고 `sync_join`을 직접 불렀더니 B의 고르는 창이 옛 오류를 단 채 열려 있었다. 사용자는 이렇게 할 수 없어 세지 않았다.
