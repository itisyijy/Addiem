## 통과한 것

- **빈 홈**: 큰 카드 두 개 + 아래 작은 Drive 링크, 안내 강요 없음. N → 새 덱 창(이름 칸에 초점), I → 가져오기. Drive가 연결 안 된 상태의 "다른 컴퓨터에서 쓰던 데이터가 있나요? · Google Drive에서 불러오기" 표시 (누르지 않았다)
- **새 덱 이름**: 빈 이름 · 공백만은 [만들기]가 꺼진다. `::`는 "이름에 :: 는 쓸 수 없어요. 하위 덱은 덱 안에서 만들어요." 같은 이름 · 앞뒤 공백 차이는 "같은 이름의 덱이 이미 있어요." 이모지 · `<b>` · 따옴표 · `%` `_` `#`는 글자 그대로 보인다(HTML로 해석하지 않음)
- **하위 덱**: 4단계까지 만들기, 넣을 곳 드롭다운(전각 공백 들여쓰기), 기본 중요도 [핵심] 적용, 부모와 같은 이름 허용, 같은 곳 같은 이름은 오류
- **이름 바꾸기**: F2 · Enter 저장, Esc 되돌리기, 바깥 클릭(blur) 저장, 형제와 같은 이름은 빨간 밑줄 + "같은 이름의 덱이 이미 있어요."를 띄운 채 편집 유지
- **잠시 쉬기**: 3일 · 2주 · 다시 시작할 때까지 · 오늘(날짜 고르기) 모두 배너 · 홈 행 · 이유 줄이 맞다. 되돌리기 토스트, 배너 [지금 다시 시작], 쉬는 중 메뉴는 [다시 시작]으로 바뀜. 기한을 어제로 바꾸고 다시 켜면 "정보처리기사 쉬기를 마쳤어요" 토스트와 함께 자동으로 풀린다. 달력 `min`이 오늘이라 과거 날짜는 고를 수 없다
- **보관 · 삭제**: 보관 → 홈 이동 + 되돌리기(약 5초) → 덱으로 복귀. 설정 › 보관한 덱의 [보관 해제] · [완전히 삭제] 확인 창. 덱 삭제는 이름을 정확히 쳐야 켜지고, 앞뒤 공백은 봐준다. "지우기 전에 백업 파일 만들기 (권장)" 기본 켜짐 · 실제로 백업이 생긴다
- **카드 추가 7가지 + 사용자 유형**: 질문과 답변 · 양방향(2장) · 빈칸(Ctrl+Shift+C 2개 → 2장, 0개는 "빈칸을 하나 이상 만들어 주세요.", 직접 친 `{{c1::}}` 같은 번호 2개 → 1장) · 서술형(모범 답안 필수, 핵심어 제안) · 그림 가리기(43칸 → 43장) · 목록(1개 오류, 11개 경고, 공백 항목 무시) · 선택형(1개 · 정답 없음 오류, 6개에서 더 안 늘어남, 정답 2개) · 내 노트 유형. 빈 칸 오류 문구가 칸마다 맞다. 저장 뒤 칸이 비고 질문 칸에 초점
- **서식 · 수식**: Ctrl+B/I/U, 목록 버튼, Ctrl+M은 `\( \)`를 넣는다. 읽지 못한 수식은 "수식 1개를 읽지 못했어요 … 고치지 않아도 저장되고"로 경고만 하고 저장된다
- **그림**: png · jpg · webp · bmp · gif · svg 붙여넣기, 같은 그림 두 번은 같은 파일 하나로 저장. 그림 가리기는 GIF · SVG를 거절하고 150px 그림에 "그림이 작아요" 경고
- **그림 가리기 편집기**: R · V, 5px 미만 도형 버림, 방향키 · Shift 방향키 이동, Ctrl+D 복제, Shift 클릭 + Ctrl+G 묶기 · Ctrl+Shift+G 풀기, Ctrl+Z · Ctrl+Shift+Z, Delete, 40칸 초과 경고, Esc → "편집을 마칠까요?"
- **유형 전환**: 서술형 → 질문과 답변에서 채점 메모가 있으면 "옮기지 못하는 칸이 있어요" 확인, [그대로 두기]로 내용 유지. 유형 제안 칩("보기 4개가 있어요 · 선택형으로 바꾸기") → 보기 4개로 나눔 → 되돌리기로 원래 글 · 유형 복귀. 덱마다 마지막 유형을 기억 ("이 덱에서 마지막으로 쓴 유형이에요.")
- **떠나기 가드**: 쓰던 중 [← 덱] · 상단 [새 덱] · 설정 모두 "작성 중인 카드가 있어요". 저장 직후 나가기는 묻지 않음. 조합 중에 Ctrl+Enter로 저장해도 조합 글자까지 저장되고 다음 칸에 남는 글자가 없다
- **카드 목록**: 100장 뒤 스크롤로 150장, 한글 검색(21장) · `tag:기출`(15장) · `tag:ch2`(8장) · 결과 0개("찾는 카드가 없어요."). 여러 장 중요도 · 이동 · 접어두기와 각 되돌리기, 기출 표시 창
- **노트 유형**: 목록 개수, 앱 기본 유형은 "볼 수만 있어요" + [복제해서 고치기], 쓰는 노트가 있으면 삭제 메뉴가 꺼지고 이유 표시, 이름 바꾸기 중복 · 앱 기본 이름("'질문과 답변'은 앱 기본 유형 이름이에요") 오류. 편집기: 필드 이름 금지 문자(`: { } "`, `# / ^` 시작) · 같은 이름 오류, "고칠 곳 1개"면 [저장] 꺼짐, 떠나기 가드. 노트 유형 바꾸기: 같은 이름 칸 자동 맞춤, 옮기기 전 백업 생성, [옮기기] 더블클릭에도 한 번만
- **페르소나 흐름**: 빈 홈 → N → "한국사 능력 검정" → A → 2장 → [추가 끝내고 학습 시작] → 요약 → Enter → 첫 카드까지 막힘 없음

### 2차에서 통과한 것

- **진짜 그림 파일 (붙여넣기 · 고르기)**: photo.png · jpg · gif · bmp, vector.svg, tiny-100px.png가 원래 크기로 들어간다. 같은 그림은 같은 파일 하나. 스크립트 든 SVG는 어디서도 실행되지 않는다 (★ 판정 표)
- **그림 가리기 그림 거절 (진짜 파일)**: photo.gif · script.svg · fake.heic → "움직이는 GIF · SVG · HEIC 그림은 쓸 수 없어요…", big-21mb.png → "이미지가 너무 커요. 20MB 이하만 넣을 수 있어요." (여기는 안내가 나온다), tiny-100px.png → "그림이 작아요 (짧은 변 100px)"
- **그림 가리기 편집기**: Ctrl+휠 확대(100 → 133%), Ctrl+- 축소, Space+끌기로 화면 이동(도형이 새로 그려지지 않음), 실행 취소 50단계 한계(55번 옮기고 60번 되돌리면 5px 남은 자리에서 멈추고 [실행 취소]가 꺼짐). 복습한 칸 지우기: 3장을 학습(Good)한 뒤 1번 칸을 지우고 저장하면 "복습한 카드 1장이 지워져요 · 1번 칸을 지웠어요. 그 카드와 복습 기록이 함께 지워져요." → Esc로 편집기에 남는다. "편집을 마칠까요?" → [바꾼 것 버리기]면 카드 3장 그대로
- **카드 편집 창 저장**: 서술형 카드에서 기출 "2025년 필기 1회" 추가(새 시험 칸, 조합 중 Enter 포함), 핵심어 "3단계" 직접 추가(조합 중 Enter 포함), 기출 팝오버 Esc는 팝오버만 닫음, [공부할 때 직접 써서 답하기] 끄기, 덱을 "1과목"으로 이동 → Ctrl+Enter 저장 → 다시 열면 넷 다 그대로이고 머리가 "정보처리기사 › 1과목"
- **[카드 삭제] 확인**: 편집 창 위에 "이 카드를 지울까요?"(카드 앞글 · 덱 · 되돌릴 수 없음), Esc는 확인 창만 닫고 편집 창은 남는다, Enter로 삭제 + "카드를 지웠어요"
- **노트 유형 편집기**: 카드 종류 추가 ([+ 카드 종류] → "카드 2 · 답변 → 질문"), 이름 바꾸기(두 번 누르기), 같은 이름이면 "'뜻 → 단어' 카드 종류가 이미 있어요." + "고칠 곳 1개" + [저장] 꺼짐, 카드 종류 지우기. 크기 L · 정렬 왼쪽이 미리보기에 반영(`nt-l nt-left`). 미리보기 앞면/뒷면 · 라이트/다크 · 미리볼 카드 고르기("바나나 · Deck"). 카드 종류별 "넣을 덱" 메뉴(모든 덱 · 하위 덱 경로) → 가리기 덱으로 저장 후 다시 열어도 유지. 필드 Alt+↑로 순서 바꾸기(필드 행에 초점이 있을 때). 카드에 쓰는 필드는 지우기가 막히고 "카드 1 앞면 · 카드 2 뒷면에서 먼저 빼면 지울 수 있어요" 안내. 저장 영향: 카드 종류를 더하면 "카드 2장이 새로 생겨요" 확인 → "카드 2장을 새로 만들었어요", 필드를 지우면 "'예문' 필드를 지울까요? … 저장하기 전에 이 기기 백업을 먼저 만들어요" → `addiem-…-notetype.zip` 백업 생성 → 숨긴 필드 1 → [되살리기] → "되살렸어요 · 카드 모양에 넣으려면…". ## 못 해 본 것

- **실제 Windows 한국어 IME**: 모든 조합 시험은 CDP `Input.imeSetComposition` 흉내다. 이 흉내는 조합 중 Enter를 `key: "Enter", isComposing: true`로 보내므로 Windows IME(첫 keydown `Process`/229)와 순서가 다를 수 있다
- **탐색기에서 실제로 끌어 놓기**: OS 수준 끌기를 만들 수 없어 Tauri 이벤트와 HTML 이벤트를 따로 흉내 냈다 (T1-05)
- **네이티브 파일 대화상자 자체**: 2차에서 CDP `DOM.setFileInputFiles`로 그 입력칸에 실제 파일을 넣어 "고르기"를 흉내 냈다. 대화상자의 `accept` 거르기(GIF · SVG가 목록에 안 보이는지)는 보지 못했다
- **진짜 HEIC 파일**: 픽스처 `fake.heic`는 내용이 PNG다 (T1-34)
- **Google Drive에서 불러오기 클릭**: 설치본 규칙상 누르지 않았다
- **노트 유형 편집기의 끌어 놓기**: 필드 → 앞/뒷면 줄 만들기 · 줄 옮기기는 HTML5 drag라 CDP 마우스로 만들지 않았다 (Alt+↑↓ 키보드 이동만 확인). 읽어주기 · 써서 답하기 칸 옵션, 다른 기기와 동시에 고친 기록(동기화 필요)
