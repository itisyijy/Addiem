## 안전 규칙 (모든 에이전트 프롬프트에 그대로 넣는다)

- **실제 데이터는 열지도 쓰지도 않는다.**
  - `%APPDATA%\io.github.itisyijy.addiem`
  - `%LOCALAPPDATA%\io.github.itisyijy.addiem`
  - 저장소 루트의 개인 `itisyijy.colpkg`
  - 설치 폴더 `%LOCALAPPDATA%\Addiem`은 실행만 하고 쓰지 않는다.
- 앱을 띄울 때마다 네 가지를 따로 준다. 하나라도 빠지면 실제 데이터를 옮기거나 쓴다(legacy 이동, 공유 키체인).
  - `ADDIEM_DATA_DIR`: 비어 있지 않은 고유 경로 ★ 빈 문자열이면 현재 폴더와 실제 키체인을 쓴다
  - `WEBVIEW2_USER_DATA_FOLDER`: 고유 경로
  - `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS=--remote-debugging-port=<고유 포트>`
- 앱은 기록한 PID로만 끈다. `taskkill /IM`은 쓰지 않는다. 다른 트랙의 CDP 포트에는 붙지 않는다.
- 도구 스크립트는 트랙마다 자기 폴더에 복사해서 쓴다(10-16 QA 때 공유 `cdp.mjs`를 덮어쓴 사고가 있었다).
- 1·2단계 설치본 인스턴스에서는 [Google Drive 연결] · [ChatGPT로 계속]을 누르지 않는다. 설치본에는 실제 Google 키가 들어 있어 진짜 로그인 창이 뜬다.
- 시스템 설정은 바꾸지 않는다: 시계, 시간대, DPI, 고대비, 네트워크 어댑터. 모두 CDP 에뮬레이션이나 DB 편집으로 대신한다.
- 패키지 설치(pip, npm)는 하지 않는다. 미리 허락받은 모델 다운로드만 한다.
- 시작하기 전에 남은 RAM을 본다. 3GB 아래면 새 인스턴스를 띄우지 않고 기다린다.

## 실행 구조

### 0단계 · 준비 (직렬, 약 30분)

**코디네이터(이 세션)가 한다.**

1. 실제 데이터 폴더 두 곳의 파일 목록(경로·크기·수정 시각)을 기록해 둔다. 맨 끝에 같은지 비교한다.
2. 디버그 exe를 한 번만 빌드한다. 가짜 AI, 가짜 동기화 폴더, LLM 시험 훅은 debug에서만 켜지기 때문이다.
   - worktree `%TEMP%\na-fq\src`에 main `2e72cd3`을 detached로 받는다. `node_modules`는 junction으로 잇는다.
   - `CARGO_TARGET_DIR=%TEMP%\na-fq\target`으로 `npm run tauri build -- --debug --no-bundle`을 돌린다.
   - 실행 폴더 `%TEMP%\na-fq\bin-debug`에 exe를 두고, 옆에 `llm\`과 `tts\`를 복사한다(`src-tauri/resources`).
   - `llm_status` · `tts_langs`로 엔진과 음성을 찾는지 확인한다.
3. release 쪽은 새로 빌드하지 않는다. 설치된 `%LOCALAPPDATA%\Addiem\addiem.exe`(0.1.0)를 그 자리에서 위 환경 변수와 함께 띄운다. 사용자가 실제로 쓰는 바로 그 바이너리다.
4. 포트 9601–9699가 비어 있는지 확인한다(`Get-NetTCPConnection`).
5. 공용 CDP 드라이버 템플릿 `%TEMP%\na-fq\tools\cdp.mjs`를 만든다. Node 24 내장 WebSocket으로 다음을 한다.
   - 클릭과 키 입력
   - `__TAURI_INTERNALS__.invoke`
   - 파일 드롭: `plugin:event|emit_to` `tauri://drag-drop`
   - 저장 대화상자 가로채기
   - 스크린샷, 콘솔·CSP 수집
   - IME 조합: `Input.imeSetComposition`
   - 에뮬레이션: 테마, forced-colors, reduced-motion, 배율

**같은 시간에 픽스처 에이전트 1개가 돈다.**

- 출력은 `%TEMP%\na-fq\fixtures`이고, 트랙은 읽기만 하고 복사해서 쓴다.
- 도구는 표준 라이브러리 Python과 기존 `%TEMP%\na-anki-venv`(Anki pylib 26.9.3)만 쓴다.

- **성능 측정은 1단계에서 하지 않는다.** 다른 트랙이 함께 돌면 숫자가 흔들리기 때문이다.
- 에이전트 프롬프트에는 다음을 넣는다.

  - 자기 트랙의 경우 목록(아래)
  - 경로·포트, 보고 파일 경로
  - "먼저 페르소나 흐름을 끝까지 한 번 돌고, 그다음 경우 목록을 하나씩 확인한다. 막히면 '못 해 본 것'에 남기고 넘어간다"

### 3단계 · 실계정 확인 (R, 사용자와 함께, 약 40분)

코디네이터가 진행하고, 로그인은 사용자가 브라우저에서 직접 한다. 비밀번호는 입력하지 않는다.

- 설치본 인스턴스 2개(실제 Google 키 포함)를 테스트 Google 계정으로 쓴다.
- ChatGPT는 인스턴스 1개로 확인한다.

### 4단계 · 정리

1. 코디네이터가 `summary.md`를 쓴다. 중복을 합치고 P0–P3을 매기며, 의심 위치를 다시 확인한다.
2. 실제 데이터 폴더 목록이 0단계 기록과 같은지 비교한다.
3. 테스트 키체인 항목이 남지 않았는지 확인한다. 테스트 앱 PID가 모두 끝났는지 확인한다.
4. worktree를 지운다. junction은 먼저 `[IO.Directory]::Delete(path,$false)`로 끊는다.
5. 스크래치 데이터를 지울지는 사용자에게 묻는다(모델 사본이 약 1.6GB × 여러 벌).
6. 메모리를 저장한다: "QA는 기본이 병렬 에이전트"(feedback).

## 트랙별 경우 목록

각 트랙은 맨 앞의 **페르소나 흐름**을 끝까지 한 번 돈 뒤, 아래 경우를 하나씩 확인한다. ★는 코드 조사에서 의심되는 곳이라 반드시 재현을 시도한다.

### T1 처음 쓰기 · 덱 관리 · 카드 작성

**페르소나**: 처음 깐 사람이 빈 홈 → [새 덱 만들기] → 카드 몇 장 추가 → 학습 시작까지 간다.

- **빈 홈(A1)**
  - 버튼 두 개만 보이는지, 안내가 강요되지 않는지
  - N과 I 단축키
  - Drive가 연결 안 된 상태의 "Google Drive에서 불러오기" 표시
- **새 덱 이름** 각각에 대해 결과와 오류 문구를 확인한다.
  - 빈 이름, 공백만, `::` 포함, 같은 이름(대소문자·앞뒤 공백 차이), 200자 이상, 이모지, 특수문자
  - ★ 한글 조합 중 Enter
  - ★ Enter 두 번 빠르게(덱 두 개 생성)
  - ★ 바깥(scrim)을 클릭하면 입력이 사라짐
- **하위 덱**
  - 3단계까지 만들기, "넣을 곳" 선택, 중요도
  - 하위 덱 이름에 부모 이름 넣기
- **이름 바꾸기**
  - F2 · Enter · blur 저장, Esc 되돌리기, 같은 이름 빨간 안내
  - ★ IME Enter (`Deck.tsx:199`)
- **잠시 쉬기**
  - 3일 · 1주 · 2주 · 다시 시작할 때까지 · 날짜 고르기(오늘, 과거 입력 시도)
  - 되돌리기 토스트, 배너의 [지금 다시 시작], 기한이 지나면 자동으로 끝나는지
- **보관과 삭제**
  - 보관 → 5초 되돌리기 → 설정 › 보관한 덱 → [보관 해제] · [완전히 삭제]
  - 덱 삭제: 이름을 정확히 입력해야 하는지, 백업 체크 기본값, 공백 차이
  - ★ 삭제 확인의 IME Enter (`Deck.tsx:1099`)
  - 같은 이름의 보관 덱이 있을 때 JSON 가져오기를 하면 보관이 조용히 풀림 (`import.rs:149`)
- **카드 추가 — 7가지 유형과 사용자 유형** 각각 저장, 빈 칸 오류 문구, 저장 후 바로 다음 카드
  - 서식 B/I/U, 목록
  - 그림: 붙여넣기 · 끌어 넣기 · 선택. png/jpg/webp/bmp/gif/svg, 20MB 초과, 같은 그림 두 번
  - 수식: Ctrl+M, 잘못된 수식 경고가 저장은 막지 않는지
  - 빈칸: Ctrl+Shift+C, 같은 번호 여러 개, 빈칸 0개
  - 선택형: 보기 1개 / 2개 / 6개 / 7개, 정답 없음
  - 목록: 1개 / 2개 / 11개(10개 초과 경고)
  - ★ Ctrl+Enter 두 번 → 중복 카드 (`AddCard.tsx:439`)
  - ★ 포커스가 body에 있을 때 Esc가 안 먹음
  - 유형을 바꿀 때 "옮기지 못하는 칸" 확인
  - 떠나기 가드: 입력 중 나가기, 저장 직후 나가기
  - 유형 제안 칩과 되돌리기, 덱별로 마지막 유형을 기억하는지
- **그림 가리기 편집기**
  - V/R/O, Delete, 화살표(Shift), Ctrl+D/G/Shift+G, 되돌리기 50단계, 확대·이동, 이름 40자
  - 5px 미만 도형, 40개 초과 경고, 짧은 변 240px 미만 경고, GIF·SVG 차단
  - 복습한 도형을 지울 때 경고
  - ★ Tab · Space 가로채기
  - ★ 이름 입력의 IME Enter
- **카드 목록(C2)**
  - 검색: 한글, `tag:`, 소리 이름 제외, 결과 0개
  - 100장 넘게 스크롤로 더 불러오기
  - ★ Ctrl+A가 불러온 행만 고름
