## 못 해 본 것

- **실제 파일 열기 대화상자 · 끌어 놓기**: 대화상자는 IPC 흉내(stubDialog)로만, 끌어 놓기는 흉내가 닿지 않아 못 했다 (T6-16은 코드로만).
- **비슷한 카드**: 초안(R1-c) 화면에만 있어 ChatGPT 연결이 필요하다. 설치본에서는 연결하지 않으므로 못 봤다 (T7 가짜 모드 범위).
- **불러오기 실패의 실제 원인**: DB 잠김 · 손상을 일으키지 않고 IPC 실패만 흉내 냈다.
- **남은 공간 부족**: 디스크를 채우지 않았다 (코드 확인만).
- **암호 걸린 PDF · 0바이트 · 깨진 PPTX**: 픽스처가 없어 넣어 보지 않았다 (T4-05에서 다룬 것).
- 자동 연결된 카드의 S 패널("자동으로 연결됨")을 학습 화면에서 직접 열어 보지는 못했다 (그 카드들이 새 카드라 학습 순서에 오지 않음). `source_for_card(56)` 이 method auto 로 제목 구간을 돌려주는 것만 확인했다. 학습 화면은 카드를 보일 때마다 연결을 새로 묻는다(`Study.tsx:33`)는 것도 확인했다.
