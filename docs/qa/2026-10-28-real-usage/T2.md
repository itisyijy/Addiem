## 통과한 것

- **페르소나 흐름**: 홈 Enter → 요약 Enter → Space · 1–4 만으로 59장(복습 21 · 신규 38) 끝까지. review_log 104건, 두 번째 Good 에서 졸업(2일), Easy 8일, 밀린 복습 `overdue=1` 기록, 끝 화면 "오늘 예정 59장 모두 봤어요 · 내일 12장(복습 2 · 신규 10)"이 DB 와 맞다.
- **D1**: 가볍게 · 권장 · 더 많이(19/38/39, 밀린 덱 219/238/239) — 고른 분량과 세션 합계가 같다. 남은 신규가 권장 이하이면 [더 많이] 숨김. 분량 버튼을 마우스로 누른 뒤 Enter 시작. [다음부터 바로 시작] 저장 후 다음 진입이 바로 학습, 설정 토글과 같은 값.
- **되돌리기**: 한 단계만, 두 번째 시도 "더 이전 평가는 되돌릴 수 없어요". 한글 자판 Ctrl+ㅋ. 앱을 다시 켠 뒤 · 세션을 이어 쓴 뒤에도 같은 안내(조용히 무시 아님). 되돌리면 review_log 행이 지워지고 카드 상태 복원. 목록(연 칸 · 빠뜨림)과 선택형(고른 보기 · 보기 순서) 답 면이 그대로 돌아온다. 빈 서술형 칸의 Ctrl+Z 가 평가 되돌리기(두 번째 Again 접기까지 풀림).
- **Again 두 번 → 접기**: 두 번째 Again `fed_to_scheduler=0`, `buried_until` = 3일 뒤 새벽 4시, 카드 상태는 첫 Again 결과 그대로. 끝 화면 [오늘 다시 보기](바로 그 카드만 학습) · [3일 뒤 다시 보기](키보드 Tab+Enter 로도). 돌아온 카드 평가는 `from_buried=1` 이고 그날 신규 한도(QA 네트워크 하루 2장)를 쓰지 않는다. 세션을 이어 쓰면 Again 횟수도 이어진다(첫 Again → Esc → 이어서 → Again = 접힘).
- **− 접기**: 토스트 "학습을 마치면 다시 볼지 물어볼게요", [지금 다시 보기], [되돌리기]. 10항목 답 카드는 [나누기 제안] → 끝 화면 행의 [나누기 제안] 칩 → 규칙 나누기 창(3장 제안). B(ㅠ) 목록 열기 · ↑↓ · Enter 꺼내기 · B · Esc 닫기, 목록이 열린 동안 Space 가 답을 열지 않음.
- **세션 경계**: Esc → 끝 화면 → [이어서 학습] → 같은 세션 이어 쓰기(`ended_at` 다시 NULL). 앱 강제 종료 뒤 다시 켜면 `app_exit` 로 닫히고 이어 쓴다.
- **학습일 경계 (DB)**: 오늘 첫 학습 기록을 03:59:59.999 로 옮기면 어제로 쳐서 홈 완료 58 · 형제 카드 1장이 다시 오늘 신규로, 04:00:00.000 이면 오늘(59 · 0장).
- **분량 규칙**: 신규 기본 20(QA 데이터베이스), 밀린 복습 200장 상한 "밀린 200 (나머지 67장은 차차)", 3장 평가 뒤 "밀린 197", 상한은 오래된 기한부터 덱을 가로질러. 양방향 · 그림 가리기 형제는 하루 1장(빈칸 제외), 빈칸 형제 사이에 다른 카드가 끼고 끼울 카드가 없으면 그대로. 쉬는 덱은 전체 학습에서 빠지고 직접 고르면 복습만(신규 0), 보관한 덱은 빠짐. 오늘 이미 평가한 노트의 카드는 오늘 다시 안 나옴.
- **유형**: 기본, 양방향, 빈칸(힌트 · c0 무시 · c10 · c99 · 수식 빈칸), 서술형, 그림 가리기(질문 칸 · 다른 칸 · 확대에도 가림 유지), 목록(Space 한 칸씩 · X(ㅌ) · Enter 모두 열기 · Hard 추천), 선택형(1–6 여러 개 고르기 · Space 확인 · 추천), 가져온 사용자 유형(QA TTS · QA 미디어).
- **키**: Space, 1–4, E(ㄷ, 편집 창 · Esc 는 창만 닫음 · 첫 칸 비우면 "첫 칸을 비울 수 없어요"), −, Ctrl+Z, S(ㄴ, 자료 패널), R(ㄱ), B(ㅠ), X(ㅌ), 1–6, Esc, ↑ ↓ PgUp PgDn End(60줄 카드), 한글 자판 상태 모두 동작.
