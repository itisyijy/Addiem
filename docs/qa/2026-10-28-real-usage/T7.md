## 통과한 것

- **페르소나 흐름**: 자료에서 구간 2개 → 초안 3장 → 1장 고침 → [다시 만들기]가 "고친 초안 1장이 있어요"를 물음 → 2장 만들기 → "카드 2장을 만들었어요 · 자료 구간과 이어 두었어요" 토스트. 서술형 학습에서 G → 확인 목록 → 채점 보조 결과와 근거 칩.
- 초안 화면에서 뒤로 · Esc는 "초안 N장을 버릴까요?"를 묻는다.
- 연결 끊기 뒤: 설정이 연결 전 화면(L1)으로, 카드 점검의 [AI로 확인]이 [카드 편집]으로 바뀌고, 초안 · 나누기 등은 L2 연결 창을 띄운다. 오답 보기 줄은 숨는다.
- 사용 횟수: "이번 달 22번 · 마지막 오늘 13:19". DB를 지난달 값(`2026-09 7`)으로 바꾸면 "이번 달 0번 · 마지막 9월 21일 23:13".
- **카드 점검 규칙 (G1)**: 긴 답(10줄) · 질문 2개 · "몇"을 묻는데 수가 없음 · 앞뒤 바뀜 · 한 줄 번호 7개를 모두 찾는다. 서식 고치기 비교(줄바꿈 6곳 · 글자 그대로) → 적용 → "최근 고친 카드"에 [전후 보기][되돌리기]. 적용 뒤 카드를 손으로 또 고치고 되돌리면 "그 뒤에 고친 내용이 있어요"를 묻고, 확인하면 원래 글로 돌아간다(DB 확인). 만든 지 7일 1시간이 지나면 목록에서 빠진다(DB 시각 수정). 30일 숨기기 → 토스트 되돌리기 · "숨긴 카드 1", 숨김 기한이 지나면 다시 올라온다. AI 나누기 적용 → "3장으로 나눴어요" → "최근 나눈 카드"에서 되돌리기.
- **모델 받기 (인스턴스 2, 실제 1.1GB)**: [받기 · 1.1GB] → 확인 창(크기 · 남은 공간 920.8GB · 모델 · Apache-2.0 · 출처 · AVX2). 받는 중 진행 "42MB / 1.1GB" → "0.5GB / 1.1GB". [멈추기] → `.part` 즉시 삭제, "내려받기를 멈췄어요 · 받던 파일은 지웠어요"(회색), 버튼 "다시 받기 · 1.1GB". 다시 받기 약 25초 만에 완료 (`model.gguf` 1,117,320,736 · `tokenizer.json` 7,031,645). [지우기] 확인 창 → 폴더 비움.
- 응답 없는 로컬 주소: 30.4초에 "연결이 멈춰 모델을 내려받지 못했어요. 인터넷 연결을 확인하고 다시 시도해 주세요." 1MB 뒤 멈추는 서버도 30.4초에 같은 문구, `.part` 정리됨. 닫힌 포트는 2.5초에 "모델을 내려받지 못했어요…".
- `ADDIEM_LLM_NO_AVX2=1`: "이 PC에서는 쓸 수 없어요" 배지 + "…AVX2를 지원하지 않아 쓸 수 없어요. 서술형 핵심어 검사와 ChatGPT 채점 보조는 그대로…", [받기] 버튼 없음, `llm_download` 호출도 거절.
- **학습 중 개념 관계 확인 (인스턴스 1)**: 질문 면이 뜨면 엔진이 바로 뜬다(약 1.9GB). 비교하면 저절로 돌아 1.7초(미리 함) · 8.7초(엔진 새로 띄움)에 결과. "참고용 · 틀릴 수 있어요" 배지, [자세히]에 "자주 틀려서 평가 추천에는 쓰지 않아요". 핵심어 추천 줄은 결과 전후 같다. 16초에 "조금 오래 걸려요 · 평가는 지금 해도 돼요". 학습 화면을 떠나면 엔진 프로세스가 끝난다.
- 엔진 강제 종료: 한 번 죽이면 다시 띄워 결과를 낸다. 두 번(미리 하던 엔진 + 다시 띄운 엔진) 죽이면 카드 안 줄 없이 토스트 "개념 관계 확인을 이번 학습에서는 껐어요 · 다음 학습에서 다시 켜져요. 핵심어 검사와 평가는 그대로예요.", `llm_status.off = true`, 핵심어 추천 그대로. 다음 학습에서 다시 켜진다(off false, 결과 나옴). 엔진 PID는 내 앱 PID의 자식만 골라 껐다.

## 못 해 본 것

- 실제 ChatGPT 계정: 로그인 · 401 재로그인 · 실제 사용량 차감 시점(응답 시작 후 취소 · 평가할 때 사용량이 실제로 줄어드는지, T7-01 · T7-05)은 3단계 실계정 확인으로 넘긴다.
- `scope`(사용량 권한 없음) · `not_eligible`(요금제 불가) 오류 화면: `ADDIEM_AI_FAKE`에 해당 값이 없다.
- 보내는 중에 [연결 끊기]로 요청이 멈추는지: 두 화면을 동시에 열 수 없어 가짜 모드로는 재현하지 못했다 (코드상 `ai_disconnect`가 run을 올린다).
- 초안의 "비슷한 카드 있음 · 근거 미확인" 칩: 분석 모델(T6)을 이 데이터에 받지 않아 "분석 모델이 없어 …하지 않았어요" 줄만 확인했다.
- 오답 보기 제안을 새 카드 추가(C3) 화면에서 따로 보지 않았다 (편집 창과 같은 컴포넌트).
- 저장 공간이 모자랄 때의 받기 확인 창: 시스템 설정을 바꾸지 않는 규칙 때문에 하지 않았다 (코드 `llm.rs:279-281`, `ConceptCheck.tsx:153`).
- 모델 받기를 `tokenizer.json` 단계에서 멈추는 경우: 실제 받기는 승인된 한 번(멈추기 + 다시 받기)으로 끝냈다.
