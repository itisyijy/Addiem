## 통과한 것

- **시작**: 빈 데이터 콜드 0.63초 · 웜 0.42초, 카드 4만 0.68–0.73초. 1초 안.
- **.apkg 가져오기**: 205 MB · 473 MB 모두 미디어 · 기록까지 다 들어오고, 그 사이 창 · 렌더러가 멈추지 않는다. 진행 단계 표시, 결과 화면 숫자(카드 · 미디어 · 기록 · 밀린 복습) 정확.
- **카드 4만 데이터의 홈 · 덱 상세 · 카드 목록 첫 쪽 · 검색(한글 · tag:) · 학습 시작 · 설정 지표 · 히트맵**: 모두 0.5초 안 (가장 느린 것 카드 목록 첫 쪽 0.46초).
- **학습**: 500장 연속 평가 지연 최대 45 ms, 메모리 증가 45 MB. 오늘 2만 장 큐도 첫 카드 67 ms.
- **백업 · 복구**: 457 MB 백업 0.53초, 복구 1.04초. 복구 뒤 홈 정상, "백업으로 복구했어요" 안내.
- **내보내기**: 미디어 452 MB 덱 1.9초. 진행 창이 떠 있는 동안 N · I · Esc · Enter · E, 뒤 화면 클릭, 설정 톱니 모두 막혀 다른 명령이 끼어들지 않는다 (실측, 창 메시지 루프 최대 0 ms).
- **배경 움직임**: 대기 CPU 코어 1개의 3%, 최소화 · 움직임 줄이기에서 0.1%로 멈춘다 (T9-06 경우 제외).
- **JSON 2만 가져오기**: 2.2초에 끝나고 결과(덱 1 · 하위 덱 5 · 카드 20,000 · 건너뜀 0)가 맞다.
