## 통과한 회귀 흐름

- **화면 × 조건**: `walk.mjs`로 34개 화면 상태 × 9조건을 돌렸다(조건은 아래). 결과:
  - 조건: P 1180×640 125% 다크 · L 1180×640 라이트 · M 1280×800 · F 1920×1080 다크 · Q 2560×1440 · S15 1280×800 150% · S2 1180×640 200% · 고대비 어둡게 · 밝게
  - 가로 스크롤 0, 창 오른쪽 밖 요소 0, 말줄임이 아닌 잘림 0, 이름 없는 컨트롤 0
  - 덮인 버튼은 잠시 쉬기 하위 메뉴 아래 "목표일 정하기"(메뉴가 덮은 것) · 스크롤된 상단 메뉴 아래뿐이다. 둘 다 T8 때와 같다
  - 잘림으로 잡힌 `cards__live`는 화면에 안 보이는 알림 영역이다
  - 가져오기(JSON) 1개는 덱 이름을 바꿔서 열지 못했다. 가져오기 화면은 따로 봤다
- **콘솔 · CSP**: 순회 34화면과 이 문서의 모든 시험에서 콘솔 오류 · 예외 · CSP 위반이 0건이다(1차 붙여넣기 · 큰 그림 거절 포함, `Uncaught (in promise)` 없음)
- **문구**: 순회 화면 글자에 "Anki" · "Neo-Anki" · 영어 오류 단어 0건. 바뀐 TSX 문자열에 합니다체 · "~다." 문장이 없다(Rust 쪽 "니다"는 시험 코드뿐). 새 문구는 모두 해요체다: 그림 거절 · 단축키 거절 · 저장 오류 · 복구 화면
- **키보드만으로 주요 흐름**(1180×640 125% 다크): 다음 흐름이 막힘 없이 된다. 콘솔 오류는 없다
  1. N → 이름 → Enter로 덱을 만든다
  2. A → 질문 → Tab 2번 → 답 → Ctrl+Enter ×2(저장 뒤 초점이 질문 칸)
  3. Esc → 덱 → Enter → 요약 Enter → Space · 3 반복
- **모달 Tab 가둠 · Esc 겹침**: 확인 창 위 Esc는 확인 창만 닫는다(카드 편집 · 나누기 · 새 덱 · 편집기 "편집을 마칠까요?")
- **고대비 복구 화면**: 아이콘 · 주 버튼이 보이고 상단 메뉴가 숨는다. 복구 화면에서 N · I가 동작하지 않는다
- **끌어 놓기 공용 훅 회귀**: 가져오기 화면에 nested.apkg를 놓으면 바로 검사한다("덱 1개 · 카드 18장")
- **넣을 곳 · 목록 · 선택형 · 서술형 칸**: 조합 Enter 대조군이 정상이다

## 못 해 본 것

- **실제 Windows 한글 IME**: CDP 조합 흉내와 `keyCode 229` 흉내만 했다. 실제 IME가 Enter를 어떤 순서로 보내는지는 사람 확인이 필요하다
- **잠긴 Drive 열기 창 암호(`sync.tsx:1233` · `:1358`)**: 잠금 + 키 없음 상태를 만들려면 V1 범위의 두 기기 흐름이 필요해 코드로만 봤다. 실제 Chromium은 `type=password` 칸에서 IME를 끈다
- **탐색기에서 실제로 끌어 놓기 · 실제 고대비 테마 · 실제 1366×768 125% 노트북 첫 창**: 이벤트 · 에뮬레이션 · 계산으로만 봤다. V4-01은 실제 노트북에서 가로 스크롤을 확인해야 한다
- **T8-10 ② `answer` invoke의 FOREIGN KEY**: 화면 경로가 아니라 판정에서 뺐다
- **T1-32의 "저장 실패 배너가 고친 뒤에도 남음"**: 이제 짝 검사가 저장 전에 잡아 백엔드 저장 오류를 만들 수 없었다. 코드상 `draft`가 바뀌면 지운다
- **스크린리더 실제 낭독**: 이름 · 역할만 DOM으로 봤다
- **조합 중 Esc**: 장부에서 "안 고침"이라 따로 시험하지 않았다
