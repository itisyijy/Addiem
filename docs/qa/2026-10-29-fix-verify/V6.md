## 통과한 회귀 흐름 (짧게)

- 새 덱 창 · 카드 추가 · 편집 창 · 목표 설정 · 계획 · 덱 삭제 · 모든 데이터 삭제: IME 가 아닌 보통 Enter 는 예전처럼 한 번에 만들기 · 저장 · 추가 · 다음 칸으로 간다. 두 번 만들어지거나 두 번 저장되는 일 없음.
- 버리기 확인(`dirty`): 안 고친 Esc 는 어디서나 바로 닫히고(편집 창 137장 · 새 덱 · 목표 설정 · 보관 덱 삭제 · 카드 추가), 고친 Esc 만 묻는다. 확인 창의 Esc 는 확인 창만 닫고 초점을 쓰던 칸으로 돌린다.
- 토스트 쌓기: 되돌리기 2개가 겹치지 않고 위로 쌓이며 선택 막대(카드 목록 아래)를 가리지 않는다. 오래된 토스트의 [되돌리기]는 자기 동작만 되돌린다. 정보 토스트는 3초 · 되돌리기 5초 뒤 사라짐.
- 가져오기 → 중요도 → 덱 → 학습 → 끝 → 홈의 숫자, 내보내기 결과(.apkg revlog 24 = 가져온 20 + 오늘 4), 백업 → 복구 → 숫자, 모든 데이터 삭제 → 그 백업으로 복구.
- 학습 화면 그만두는 길: Esc(끝 화면), 끝 화면 Ctrl+Z → 그 카드로 다시 → 다시 평가 → 끝 화면 숫자 그대로.
- 미디어 덱 학습: 그림 · 한글 이름 그림 표시, 없는 소리 칩 "소리 파일을 찾을 수 없어요 · missing.mp3", 없는 그림 "[그림 없음: ghost.png]", CSP 0.
- 하루 시작 시각 변경이 홈 날짜 · D-day · 오늘 완료에 바로 반영된다.
- 화면 응답: 어느 흐름에서도 멈추거나 계속 도는 화면 없음(가져오기 · 내보내기 · 백업 · 복구 모두 2초 안).
