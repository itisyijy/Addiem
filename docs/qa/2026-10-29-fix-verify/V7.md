# 다시 QA · V7 성능 · 대용량 (2026-10-29, 단독)

- **날짜**: 2026-10-29 (진행 10:27–11:30, 이 PC에서 앱 하나만)
- **대상**: `fix/v0.1.1` `24fa0b7` (`git -C %TEMP%\na-fx0 log --oneline -1` → "24fa0b7 fix: round 3 polish for undo, D1 counts, toasts over dialogs and focus return"), release 빌드 `%TEMP%\na-fx-qa\bin-release\addiem.exe` (제품 버전 0.1.1)
- **목적**: 원래 성능 QA(T9, 0.1.0 = 2e72cd3)의 T9-01–T9-06을 같은 방법으로 다시 재고, 앞뒤 숫자를 견준다. T9보다 20% 넘게 나빠진 숫자는 회귀 후보로 적는다. 찾기만 하고 고치지 않는다.

- **20% 넘게 나빠진 숫자의 원인 가르기**: 환경 차이(날짜가 하루 지나 밀린 카드 620 → 907장, 다른 앱 창이 앞에 있음, 여유 RAM 16 → 14 GB)와 코드 차이를 가르려고, 같은 4만 장 데이터 사본 두 벌에 **고치기 전 debug(2e72cd3, `%TEMP%\na-fq\bin-debug`)와 고친 뒤 debug(24fa0b7, `%TEMP%\na-fx-qa\bin-debug`)** 를 각각 띄워 같은 명령 · 화면을 쟀다 (debug 끼리만 견준다).
