## 통과한 회귀 흐름

- **키보드만으로 59장 세션** (data1): 홈 Enter → 요약 Enter → Space · 1–4 로 끝까지(평가 106건). 중간에 E(편집 창 열기) → Esc(창만 닫힘), −(접기 토스트 "학습을 마치면 다시 볼지 물어볼게요" [지금 다시 보기] [되돌리기]) → Ctrl+Z(접기 풀림, 진행 32 → 31), Space → Ctrl+Z("더 이전 평가는 되돌릴 수 없어요", 한 단계만), Esc(끝 화면). S 는 연결 자료가 있는 data3 카드에서 패널 열림.
- **학습 단계 · 이어 쓰기**: Again 횟수는 되돌린 뒤에도 이어져 두 번째 Again 에서 접힘(fed=0). 같은 날 그만둔 세션 이어 쓰기, 노트 유형 편집기에서 돌아오면 같은 세션.
- **하위 덱 학습 예산**: TCP 만 골라 학습해도 신규 2장 = 상위 표 몫, 끝난 뒤 UDP 0장 · 상위 0장.
- **목표 · 계획 화면 편집**: 목표일 내일 → 32장 · 1년 뒤 → 1장, 오늘만 분량 [자동], "다시 나누기" 끄고 바로 Esc → 저장됨("하루 신규 4장으로 고정했어요"), 시간 [−] 로 "안 정함"(설정 행 삭제).
- **끝 화면 되돌리기 (정상 경우)**: 마지막 카드를 − 로 직접 접고 끝난 끝 화면에서 Ctrl+Z → 접기가 풀리고 그 카드로 다시 들어감(`buried_until` 비움).
