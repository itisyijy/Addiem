## 통과한 회귀 흐름

- **키보드만으로 68장 세션** (data3): 홈 Enter → 요약 Enter → Space · 1–4 로 끝까지 133번 평가. 서술형은 쓰기 칸 Esc → Space, 목록은 Enter. 중간에 E(편집 창) → Esc 로 창만 닫힘, − (접기 토스트) → Ctrl+Z 로 풀림, Space → 평가 → Ctrl+Z(한 단계) → 다시 Ctrl+Z "더 이전 평가는 되돌릴 수 없어요". 같은 카드 Again 두 번 → 자동 접기. 진행 숫자가 뒤로 가지 않고, 머리는 "68/68 · 남은 0장 · 다시 볼 50장" → 0 으로 줄어듦. 콘솔 오류 · 예외 0
- **접은 카드가 있는 끝 화면**: "오늘 예정 68장 모두 봤어요" + 접은 카드 1장 + [마지막 평가 되돌리기]. Ctrl+Z → 마지막 카드 "1 / 1" → Esc → 버튼 없음, 접은 카드 목록 그대로. Tab 순서 [홈으로] → [이어서 학습] → [3일 뒤 다시 보기] → [오늘 다시 보기 · 1장], Enter 로 접은 카드 학습 → 평가 → 끝 화면(그 평가만 되돌리기 가능)
- **덱 목표 설정 저장 · 떠나기**: 목표일 11/10 입력 → Esc · 뒤로 링크 · [취소] 모두 "고친 내용이 있어요" (Esc = 계속 고치기) → [저장] → 덱 상세 "D-12 · 남은 신규 8장 ÷ 12일 = 하루 1장", `deck_config` 저장. [버리고 나가기] 는 저장 안 함
- **학습 계획 편집**: 평일 [+] 0.3초 간격 세 번 5 → 10 → 15분, 빠르게 세 번 → 30분 → 곧바로 Esc → 다시 열어도 30분, `plan_setting weekday_min 30`
- **카드 추가 7유형 저장 후 바로 다음 카드**: 질문과 답변 2 · 양방향 1(2장) · 빈칸 2 · 서술형 2 · 목록 2 · 선택형 2 · 그림 가리기 3. 매번 칸이 비고 초점이 첫 칸(가리기는 그림 칸), "이번에 N장 추가함" 이 오르고 DB 노트 내용이 맞다. 목록 항목 · 선택형 보기는 Enter 로 다음 줄
- **좁은 창 긴 이름**: 50자 덱 이름 · 띄어쓰기 없는 긴 질문이 1091 폭 홈 · 덱 · 카드 목록에서 넘치지 않음
- **기타**: 혼합 회독 한 바퀴(26번 평가) · [처음부터 다시] 확인 뒤 0%, 목표 설정 [저장] 한 번, 중요도 연쇄 Esc/뒤로 링크, `whole.colpkg` 덱 고르기 화면, 카드 점검 → 나누기 제안 창. 모든 실행에서 화면 콘솔 오류 · 예외 0
