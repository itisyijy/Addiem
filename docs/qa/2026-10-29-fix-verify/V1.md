## 통과한 회귀 흐름

- **두 기기 기본 수렴**(A · B, 화면 밖 invoke): 따로 고친 노트가 양쪽에 같다. 같은 카드를 A(Good) · B(Again)로 복습 → 기록 2건씩, FSRS 상태(state · stability · difficulty · due · reps · lapses) 같음. 72장 일괄 지움 · 1장 지움이 다른 기기로 퍼짐.
- **충돌 기록(K7)**: 같은 필드를 A 먼저 · B 2초 뒤 → B로 수렴, 양쪽 K7에 두 버전, `sync_conflicts`에 기기 이름 · 현재 표시. A에서 [이 버전으로 바꾸기](`sync_conflict_use`) → B에도 퍼짐.
- **잠금 켜기 · 끄기**(화면 · 다른 기기): 켜면 B에 "다른 기기에서 Drive 데이터를 암호로 잠갔어요" + 암호 칸, [합치기]는 암호 전까지 꺼짐, 틀린 암호 "암호가 맞지 않아요", 맞는 암호로 잠근 동안의 수정까지 받음. 끄면 B에 "…잠금을 풀었어요 · 이 기기에 저장된 암호는 더 이상 쓰지 않아요" → 합치기 → 잠금 푼 뒤 수정 받음. 잠그기 전 Drive 백업을 복구해도 잠금 · 암호화(`NAE1`)가 유지됨(앱을 다시 켠 뒤도).
- **처음 연결 · 고르는 창**: [두 데이터 합치기] · [Drive 데이터로 바꾸기] 문구, 이 기기 숫자, 잠긴 Drive의 K6-f 암호 칸.
- **K9 Drive 복구**: 미리보기(빠지는 변경 1건, 고르게 될 기기) → 복구 → 다른 기기 고르는 창 → 합치기(복구 전 이 기기 내용도 다시 올라감).
- **이 기기 백업**: [백업 만들기], [백업 고르기] → 복구 → 새로 고침 + "…백업으로 복구했어요 · 복구 전 상태도 백업해 뒀어요". 위험한 zip(경로 넘김 `bad-traversal.zip`)도 목록에만 보이고 지금 데이터를 건드리지 않음.
- **자동 백업 정리**: 최근 10개 + 7일, 직접 만든 백업 · 넣은 zip · `-wipe`는 남김.
- **연결 끊기**: [Drive 데이터 남기기] → 다시 연결 시 고르는 창. [끊고 Drive에서 지우기] → Drive 파일 · `kdf/` 삭제, 키체인 키 삭제.
- **옛 빌드 → 새 빌드**: 2e72cd3로 맞추던 Drive를 새 빌드가 그대로 읽고 이어서 맞춤(K45 · K46 시험 중).
