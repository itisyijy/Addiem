## 통과한 회귀 흐름

- **가짜 모드 × 기능 표 (T7과 같은 `matrix.mjs`)**: 7개 모드 × 5곳 모두 T7 표와 같은 진행 표시 → 결과(오류 제목 · 버튼)를 냈다. 바뀐 곳은 T7-08 · T7-09의 고친 문구뿐이다. 보낸 수: ok · slow · malformed는 +1, limit · expired · offline · unavailable은 +0. 깨진 응답(malformed)은 다섯 곳 모두 한 조각도 쓰지 않았다. 콘솔 오류 · 예외 0건 (`V5\matrix-<모드>.json`, 캡처 `m-<모드>-<기능>-*.png`).
- **처음 보낼 때 확인**: 새 프로필에서 채점 보조 · 나누기 · AI로 확인은 보낼 내용 목록을 먼저 보이고, 오답 보기는 나누기에서 확인한 뒤 묻지 않고 보낸다(T7-14 그대로). 초안은 창 자체가 확인.
- **보낸 횟수**: 설정 "이번 달 24번 · 마지막 오늘 03:10"이 `ai_status.sent_month` 24와 같다. 취소한 가짜 요청은 세지 않는다.
- **개념 관계 확인**: `T7 서술` 학습 질문 면에서 엔진이 뜨고(약 1.9GB), 비교 1.8초에 "확인하고 있어요 · 평가는 지금 해도 돼요 · 멈추기", 2.7초에 "맞아 보여요 5". [자세히]에 관계 5줄. 학습을 떠나면 엔진 프로세스가 끝난다 (c30-concept-done · c30-concept-open).
- **학습 자료 기본**: PDF · PPTX 두 개 한 번에 넣기, 스캔본 "글자를 읽을 수 없어요", 분석 뒤 자동 연결, 미연결 강조 구간 · 그림·표 탭, PPTX 차례로 만들기 → 표 창, PDF 끌어 잡기 → 메뉴 → 표 창.
- 장부에 없는 T6-12(그림 이름표 "Figure" 번호 빠짐)는 그대로다.

- **학습 중 S 패널**: `T7 서술` 첫 카드(구간에 직접 연결) 비교 화면에서 S → "연결 자료 · T7-자료.pptx · 슬라이드 1 · 직접 연결함 · [학습 자료에서 열기][연결 바꾸기]" (async로 바뀐 `source_for_card`).
- **연결 칸 Esc (T6-01 둘레)**: [기존 카드 연결] 검색 칸에 초점이 있을 때 Esc는 연결 칸만 닫는다. 연결 칸과 구간 메뉴가 함께 열려 있으면 Esc는 메뉴만 닫는다.

## 못 해 본 것

- **실제 ChatGPT**: 로그인 · 실제 사용량 차감(R-05 "이미 보낸 요청은 끝까지 가서 사용량을 쓴다"는 백엔드 그대로) · R-06 실제 응답 문구. 가짜 모드만 썼다.
- **분석 모델을 실제로 받는 중 다시 들어오기 · 그 화면에서 [멈추기]**: 인터넷 받기 금지. 분석 모델 쪽 성공은 "받기 직전에 모델 파일을 넣어 해시 확인만으로 끝나게" 흉내 냈고, 실패는 로컬 프록시로 냈다. 이 두 흉내에는 진행 이벤트가 없어 다시 들어온 화면에 [멈추기]가 나오지 않았다(V5-01). 다시 들어온 화면의 [멈추기]는 개념 관계 모델(로컬 서버, 진행 이벤트 있음)로만 확인했다.
- **탐색기에서 실제로 끌어 놓기**: `tauri://drag-drop` 이벤트 흉내만. 끌고 있을 때의 "놓으면 학습 자료로 넣어요" 줄(drag-enter)은 보지 않았다.
- **실제 파일 열기 창**: 대화상자 흉내(`stubDialog`)만.
- **실제 DB 잠김 · 손상으로 인한 불러오기 실패**: IPC 응답을 가로채 흉내 냈다 (T6-02).
- **초안 화면 [다시 만들기] 창을 보내는 중에 닫기**: 같은 `DraftSend` 컴포넌트라 첫 창으로만 봤다.
- 오답 보기 제안을 학습 중 편집(E)과 새 카드 추가 화면에서 따로 보지 않았다 (카드 목록 편집 창과 같은 컴포넌트).
- `scope` · `not_eligible` 오류: 가짜 모드 값이 없다 (T7과 같음).
