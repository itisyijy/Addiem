## 못 해 본 것

- **실제 Windows 한글 IME · 실제 탐색기 끌어 놓기 · 실제 열기/저장 창**: CDP 흉내로만 봤다 (IME 는 T8 모델, 끌어 놓기는 Tauri 이벤트, 창은 IPC 가로채기). 특히 V2-01 의 "조합 중 바깥 클릭" 은 흉내에서 compositionend 가 오지 않아 실제 IME 순서와 다를 수 있다 (조합 없이 적어도 같은 결과라 문제 자체는 IME 와 무관).
- **하네스 F1 (`real_anki.py all`, cargo 빌드)**: 빌드 비용 때문에 돌리지 않았다. 대신 같은 스크립트의 `make` 단계로 만든 실제 Anki 패키지를 release 화면으로 가져와 필터 덱 카드 기한을 Anki 기준값과 비교했다 (P0-5 행).
- **시간 측정 (T9-01 · T9-04)**: 기능만 봤다. 시간 판정은 V7.
- **안 고침 T4-09 "새 노트 0개만" 선택지 · T4-30 EUC-KR "똠"**: 위 판정 표 참고.
- **검색 입력 150ms 안에 Ctrl+A** 같은 목록 새로 읽기와 겹치는 경쟁은 시도하지 않았다.
- **분 단위 학습 카드가 필터 덱에 있는 패키지**: 실제 Anki 패키지에는 필터 덱에 복습 카드만 있었다. `REAL_DUE` 의 "학습 카드(epoch 초)" 갈래와 `odue = 0` 갈래는 화면으로 보지 않았다.
